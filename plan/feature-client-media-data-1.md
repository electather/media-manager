# Introduction

![Status: Planned](https://img.shields.io/badge/status-Planned-blue)

Implementation plan for the client-side media data layer. Adds a single `media` entity collection (TanStack DB, `localOnlyCollectionOptions`) feeding both home rows and peek modal, plus reference collection `homeRowItems` (`localOnlyCollectionOptions`) and a network-fed `homeLayout` singleton (`queryCollectionOptions`). Wires server endpoints `media.get` / `media.getMany` and canonicalizes the wire shape via a shared `MediaDetail` Zod schema in `@ent-mcp/shared/media`. Replaces all client mock data (`features/media/lib/mock-data.ts`, `find-item.ts`, in-route mock builders) with live RPC reads.

Two-phase plan. **Phase 1 (T47)** ships shared schema + server endpoints + mapper. **Phase 2 (T48)** ships client collections, hooks, component wiring, fallow zone, mock removal. T48 is blocked by T47.

Read-only scope. Mutations (notes, votes, requests live wiring, `media.getMany` caller) deferred to T46.

Canonical input: `docs/2026-05-01-client-media-data-design.md` (v1.1, after review pass).
SPEC anchors: §I.media-data, §C17 (amended), §C20, §V70 (carve-out), §V74 (amended), §V78–V90, §T46, §T47, §T48.

## 1. Requirements & Constraints

- **REQ-001**: Single `media` entity collection in `apps/client/src/features/media/data/media.collection.ts`. Keyed by `id`. Row = `MediaDetail & { _detailFetchedAt: number | null }`. Uses `localOnlyCollectionOptions` (no queryFn — write-driven). (SPEC §I.media-data, §C17, §V89)
- **REQ-002**: `homeLayout` singleton (`queryCollectionOptions`, sole network fetcher) holds hero pointer + row stubs + per-row cursors + `pagesLoaded` counter. `homeRowItems` (`localOnlyCollectionOptions`) holds `{rowId, mediaId, position, cursor}` reference rows with composite id `${rowId}:${cursor ?? "first"}:${position}` (V18). (SPEC §V89)
- **REQ-003**: `home.getLayout` and `home.getRowContent` server contracts unchanged on the wire. `homeLayoutCollection.queryFn` is the sole writer for layout row + side-effects `writeCompactToMedia(res.hero.item)`. Sync helpers ⊥ `homeLayoutCollection.utils.writeUpsert`. (SPEC §V89)
- **REQ-004**: New server endpoints `POST /api/media/get { id }` and `POST /api/media/getMany { ids }`, both `requireSession`. `media.getMany` shipped + tested but caller deferred to T46.
- **REQ-005**: Shared schema `MediaDetail` (`packages/shared/src/media/types.ts` + `schemas.ts`) is the single wire-shape source. `CompactMediaItem = Pick<MediaDetail, COMPACT_FIELDS>` derived. `@ent-mcp/shared/home` `CompactMediaItem` re-exports the derived type. (SPEC §V84)
- **REQ-006**: `MEDIA_ID_REGEX` exported from `@ent-mcp/shared/media` is sole regex source — `peekSchema`, `mediaGetInputSchema`, `mediaGetManyInputSchema` all import it. (SPEC §V90)
- **REQ-007**: Hydration tracking via `_detailFetchedAt: number | null`. TTL = 1h, gated solely by `ensureDetail` via `queryClient.fetchQuery` `staleTime`. ⊥ time math elsewhere. (SPEC §C20, §V87)
- **REQ-008**: Snappy detail UX: opening peek with a known id renders compact data immediately (`isHydrating=true`); detail RPC fills missing fields. Cold peek (id absent from collection) renders `{ item: null, isHydrating: true, isFullyLoaded: false }`. (SPEC §V83, §V88)
- **REQ-009**: All three collections set `meta.persist=true`. Verify `meta.persist` honored on `localOnlyCollectionOptions` path during TASK-010 (option key may differ from `queryCollectionOptions`). (SPEC §V89, §I.media-data)
- **REQ-010**: Hooks (`features/media/data/media.hooks.ts`) sole consumer surface: `useHomeLayout`, `useHomeRow`, `useMediaRow`, `useMediaDetail`. Components ⊥ import collections. ⊥ `_detailFetchedAt` import in component files. (SPEC §V73, §V83)
- **REQ-011**: `useHomeRow` joins `homeRowItems` × `media` via TanStack DB live-query `innerJoin` (V74 entity-↔-reference). Stale-ref handling via `compact()` from `es-toolkit/array` (⊥ raw `.filter(Boolean)` per SPEC §V50/§V86). (SPEC §V82, §V86)
- **REQ-012**: `writeCompactToMedia` strips undefined fields via `omitBy(isNil)` (`es-toolkit/object` + `/predicate`) before merge — undefined ⊥ overwrite existing. Detail-only fields preserved across compact-write. (SPEC §V79)
- **REQ-013**: Server mapper `apps/server/src/media/mappers.ts` deterministic — same `raw` → same `MediaDetail`. ⊥ `Math.random`. ⊥ `Date.now()` / wall-clock. CI grep guard. (SPEC §V85)
- **REQ-014**: `home/compact.ts:toCompact(item, extras)` refactored to delegate to `toCompactFromRaw` preserving extras-merge semantics. Snapshot-pin row JSON pre-refactor; post-refactor diff = byte-identical or documented intentional drift. (design §R6)
- **REQ-015**: Rename `kind` → `mediaType` ∀ media components (current `MediaDetailItem.kind` ≠ shared `MediaDetail.mediaType`).
- **REQ-016**: Delete `features/media/lib/mock-data.ts`, `lib/find-item.ts`, in-route mock builders, local `PEEK_ID_REGEX`. Rewrite `trailer-overlay.tsx` + `seasons-list.tsx` (both currently consume mocks). CI grep guard for V12. (SPEC §V12)
- **REQ-017**: Add `client-feat-media` fallow zone covering `apps/client/src/features/media/**`. Allow list: `client-feat-requests`, `client-shared-{ui,components,hooks,lib}`, `shared-pkg`. Stale `client-feat-media-details` zone (path `features/media-details/**` does not exist) → rename or delete. (SPEC §V60)
- **REQ-018**: Changeset entry `@ent-mcp/client: minor` for T48 PR (1–2 non-technical sentences per memory #11). T47 server-only PR ships empty-frontmatter changeset (internal-only).
- **SEC-001**: `media.get` and `media.getMany` both gated by `requireSession`. Per-user dispatch via `MediaService(userId)`. ⊥ admin variant in this PR.
- **SEC-002**: `media` collection `meta.persist=true` — mediaId, status, progress are user-personalized but ⊥ sensitive credentials/tokens; safe to persist.
- **CON-001**: ⊥ realtime layer (SSE/WS).
- **CON-002**: ⊥ pull-to-refresh / manual invalidation UI.
- **CON-003**: ⊥ search / discover route wiring.
- **CON-004**: ⊥ image proxy / artwork pipeline; use server-supplied URLs as-is.
- **CON-005**: Entity-collection carve-out limited to `{ media }`. ⊥ extending to other features without spec amend (SPEC §C17).
- **CON-006**: `vp add` / `vp check` / `vp test` exclusively. Pre-commit `vp check && vp test` per memory #9.
- **CON-007**: Mutations stay react-query-cache-backed (T46 future).
- **GUD-001**: `es-toolkit` submodules for utility code (`omitBy`, `isNil`, `pick`, `compact`). ⊥ inline reimpl. (SPEC §C11)
- **GUD-002**: Collection `id` stable string per `${domain}.${endpoint}[.${param}]`. (SPEC §V71)
- **PAT-001**: Sync write order = `media` first, reference rows second. (SPEC §V86)
- **PAT-002**: `writeCompactToMedia` ⊥ overwrite full-row detail-only fields. Refresh compact subset only. (SPEC §V79)
- **PAT-003**: `writeFullToMedia` always sets `_detailFetchedAt = Date.now()`. (SPEC §V80)
- **PAT-004**: `homeLayoutCollection.queryFn` sole layout writer. Cursor advancement via `queryClient.setQueryData(["home","layout"], ...)`, ⊥ collection writeUpsert. (SPEC §V89)
- **PAT-005**: Single live-query `innerJoin` permitted (entity-↔-reference). Other join shapes require spec amend. (SPEC §V74)

## 3. Alternatives

- **ALT-001**: **Per-endpoint collections (no entity layer).** Rejected — duplicates rows, blocks "snappy detail from list" goal because list-collection row and detail-collection row are separate cache entries that can drift.
- **ALT-002**: **Field-presence hydration tracking** instead of `_detailFetchedAt`. Rejected — ambiguous when detail genuinely lacks cast (e.g. documentary); can't distinguish "absent" from "not yet fetched".
- **ALT-003**: **Two-shape entity row** (`CompactMediaItem & Partial<MediaDetailExtras>`). Rejected — single shared `MediaDetail` superset is simpler.
- **ALT-004**: **Lazy seasons** (separate endpoint per season). Rejected — typical TV detail payload small (~6 × ~9 eps); lazy adds complexity without payload pain.
- **ALT-005**: **Client-side mapper.** Rejected — duplicates plugin-shape knowledge across client + server, contradicts SPEC V1, pushes plugin coupling into `@ent-mcp/shared`.
- **ALT-006**: **Single PR for T47 + T48.** Rejected — T47 is internal-API only; T48 is the user-visible flip. Two-PR split allows isolated review/rollback. Phase-coupling note: shared-pkg version bump deferred to T48 (TASK-035) to avoid wiping T43 IDB on T47-only release.
- **ALT-007**: **Use `queryCollectionOptions` for `media` + `homeRowItems` with `staleTime: Infinity` + all `refetchOn*: false`.** Rejected — works but obscures intent; `localOnlyCollectionOptions` is the canonical local-only path. Falls back to ALT-007 only if `meta.persist` ⊥ honored on local-only path (TASK-020 verification gate).

## 7. Risks & Assumptions

- **RISK-001**: **(resolved → REQ-001/REQ-009/CON-005)** `localOnlyCollectionOptions` codified for `media` + `homeRowItems` to avoid react-query refetch overwriting writes. TASK-020 verifies `meta.persist` honored on local-only path; ALT-007 documents fallback.
- **RISK-002**: **(resolved → REQ-014/TASK-014)** Home server refactor risk — snapshot-pin OR equality-test gate covers byte-identical post-refactor.
- **RISK-003**: PersistQueryClientProvider hydration race — phase 1 R2 documented acceptable. Same here.
- **RISK-004**: **(resolved → TASK-021/PAT-004)** `LayoutHero.item` split via `homeLayoutCollection.queryFn` side-effect.
- **RISK-005**: Schema validation cost. **Mitigation**: skip parse on server-sync writes per V70 + entity-collection carve-out.
- **RISK-006**: **(resolved → REQ-012/TEST-008)** Compact-during-detail race — `omitBy(isNil)` + V80 timestamp write.
- **RISK-007**: **(mitigated → ALT-006/TASK-035)** Shared-pkg version bump deferred to T48 to avoid IDB wipe on T47-only release.
- **RISK-008**: Cold peek for ids absent in any plugin — server returns 404. Client: full-page route renders `<NotFound />` (TASK-036); peek modal closes on null + ⊥ hydrating (TASK-031).
- **RISK-009**: **(resolved → REQ-007/V81)** Concurrent `useMediaDetail(id)` dedup.
- **RISK-010**: TanStack DB live-query `innerJoin` API may not exist or may evolve in v0.x. **Mitigation**: pin version + verify in TASK-024; fall back to two `useLiveQuery` + memoized merge.
- **RISK-011**: `meta.persist=true` honored on `localOnlyCollectionOptions` — option key may differ. **Mitigation**: TASK-020 verification gate; ALT-007 fallback.
- **RISK-012**: Stale `client-feat-media-details` zone in `.fallowrc.json` (path `features/media-details/**` does not exist) is a pre-existing drift — TASK-018 must rename to `client-feat-media`. ⊥ orphan zone post-PR.
